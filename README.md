# 블롭 배구 (Blob Volleyball)

브라우저에서 바로 즐기는 2D 배구 웹게임이에요. 동글동글한 캐릭터를 골라 네트 너머로 공을 넘기고, 먼저 15점을 내면 이겨요. 설치할 패키지 없이 `index.html` 하나로 동작해요.

> 배포 주소: https://cute-parfait-531fc8.netlify.app (Netlify)

## 특징

- **컴퓨터 대결**과 **둘이서 대결(한 키보드)** 두 가지 모드
- 캐릭터 4종 선택: 펭펭(펭귄), 개굴(개구리), 몽실(양), 냥이(고양이) — 모두 오리지널 캐릭터
- 공중에서 쓰는 **스파이크**, 효과음, 15점 선승제
- PC 키보드와 모바일 터치 모두 지원 (모바일은 컴퓨터 대결만)
- 외부 라이브러리 없음: HTML + Canvas + 바닐라 JavaScript

## 조작 방법

### 키보드

| | 1P | 2P |
|---|---|---|
| 이동 | `A` `D` | `←` `→` |
| 점프 | `W` | `↑` |
| 스파이크 (공중에서) | `S` | `↓` |

- 컴퓨터 대결에서는 1P가 WASD와 방향키를 모두 쓸 수 있어요.
- 스파이크는 점프 한 번에 한 번만 쓸 수 있어요.
- `Esc`를 누르면 메뉴로 돌아가요.

### 캐릭터 선택

- 1P: `A` `D`로 고르고 `W`로 확정, `S`로 취소
- 2P: `←` `→`로 고르고 `↑`로 확정, `↓`로 취소
- 컴퓨터 대결에서는 카드를 눌러서 골라도 돼요. 컴퓨터는 다른 캐릭터를 무작위로 골라요.

### 모바일 (컴퓨터 대결)

화면을 가로로 돌리면 아래 버튼이 나와요.

- 왼쪽 아래: ◀ ▶ 이동
- 오른쪽 아래: 점프, 스파이크
- 오른쪽 위: 메뉴

## 실행 방법

### 방법 1. 파일 바로 열기

`index.html`을 브라우저로 열면 돼요.

### 방법 2. 간단한 서버로 실행 (Node.js 필요)

```bash
node server.js
```

브라우저에서 `http://localhost:3004`로 접속해요. 포트를 바꾸려면 이렇게 실행해요.

```bash
PORT=3005 node server.js
```

같은 와이파이에 있는 폰에서는 `http://(PC의 IP 주소):3004`로 접속할 수 있어요.

### 방법 3. 정적 호스팅에 올리기

`index.html`만 있으면 되기 때문에 Netlify, Cloudflare Pages, GitHub Pages 같은 무료 정적 호스팅에 그대로 올릴 수 있어요. 이 프로젝트는 Netlify로 배포했고, 방법은 아래에 적어 뒀어요.

## Netlify로 배포하기

Netlify Drop을 쓰면 폴더를 끌어다 놓는 것만으로 배포할 수 있어요. 서버 설정이나 빌드 과정이 필요 없어요.

1. 새 폴더(예: `volley`)를 만들고 `index.html`을 넣어요. 파일 이름은 꼭 `index.html`이어야 하고, `server.js`는 필요 없어요.
2. 브라우저에서 `app.netlify.com/drop`에 접속해요. 로그인 없이도 올릴 수 있어요.
3. 폴더를 업로드 영역으로 끌어다 놓아요.
4. 몇 초 뒤 `○○○.netlify.app` 형태의 주소가 만들어져요.

### 사이트 유지하기

가입 없이 올린 사이트는 **한 시간만 유지되는 임시 사이트**예요. 이 동안에는 화면에 나온 비밀번호를 입력해야 접속할 수 있어요. 계속 쓰려면 한 시간 안에 아래 순서로 진행해요.

1. 화면의 **Claim this site** 버튼을 눌러 무료로 가입해요(구글 계정으로 가능).
2. 프로젝트 화면의 **Make public** 버튼을 눌러 공개로 바꿔요. 이렇게 해야 비밀번호 없이 누구나 접속할 수 있고 폰에서도 열려요.

### 수정한 게임 다시 올리기

Netlify에서 해당 사이트의 배포(Deploys) 화면을 열고, 수정한 폴더를 같은 방식으로 끌어다 놓으면 주소는 그대로 두고 내용만 바뀌어요.

> Netlify 화면 구성과 무료 한도는 바뀔 수 있어요. 최신 내용은 Netlify 사이트에서 확인해 주세요.
