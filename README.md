# 블롭 배구 (Blob Volleyball)

브라우저에서 바로 즐기는 2D 배구 웹게임이에요. 동글동글한 캐릭터를 골라 네트 너머로 공을 넘기고, 먼저 15점을 내면 이겨요. `index.html` 파일 하나로 동작해요.

> 배포 주소: https://cute-parfait-531fc8.netlify.app (Netlify)

## 특징

- **컴퓨터 대결**과 **둘이서 대결(한 키보드)** 두 가지 모드
- 게임 시작 전 캐릭터 선택: 펭펭(펭귄), 개굴(개구리), 몽실(양), 냥이(고양이) — 모두 오리지널 캐릭터
- 공중에서 쓰는 **스파이크**, 효과음, 15점 선승제
- PC 키보드와 모바일 터치 모두 지원 (모바일은 컴퓨터 대결만)

## 조작 방법

### 키보드

| | 1P | 2P |
|---|---|---|
| 이동 | `A` `D` | `←` `→` |
| 점프 | `W` | `↑` |
| 스파이크 (공중에서) | `S` | `↓` |

- 컴퓨터 대결에서는 1P가 WASD와 방향키를 모두 쓸 수 있어요.
- 스파이크는 점프 한 번에 한 번만 쓸 수 있어요.
- `Esc`를 누르면 메뉴로 돌아가요.

### 캐릭터 선택

- 1P: `A` `D`로 고르고 `W`로 확정, `S`로 취소
- 2P: `←` `→`로 고르고 `↑`로 확정, `↓`로 취소
- 컴퓨터 대결에서는 카드를 눌러서 골라도 돼요. 컴퓨터는 다른 캐릭터를 무작위로 골라요.

### 모바일 (컴퓨터 대결)

화면을 가로로 돌리면 아래 버튼이 나와요.

- 왼쪽 아래: ◀ ▶ 이동
- 오른쪽 아래: 점프, 스파이크
- 오른쪽 위: 메뉴

## Netlify로 배포한 과정

별도의 서버 없이 Netlify Drop에 `index.html` 파일을 올려서 배포했어요.

1. `index.html` 파일을 준비해요.
2. 브라우저에서 `app.netlify.com/drop`에 접속해요. 로그인 화면 없이 업로드 화면이 바로 나왔어요.
3. `index.html` 파일을 업로드 영역으로 끌어다 놓아요(드래그 앤 드롭).
4. 잠시 뒤 "project is live" 화면이 나오고 `https://cute-parfait-531fc8.netlify.app` 주소가 만들어져요.
   - 이 상태는 **한 시간만 유지되는 임시 사이트**예요. 화면에 남은 시간이 타이머로 표시돼요.
   - 임시 사이트는 화면에 표시되는 비밀번호로 보호돼요. 접속할 때 그 비밀번호를 입력해야 해요.
5. 화면의 **Claim this site** 버튼을 눌러 무료로 가입하고, 사이트를 내 계정에 연결해요.
6. 가입하면 "Your project is ready!" 화면이 나와요. 이때 사이트는 내 팀에게만 보이는 상태예요.
7. **Make public** 버튼을 눌러 공개로 바꿔요.
8. 이제 주소로 접속하면 누구나 게임을 할 수 있어요. 폰에서는 화면을 가로로 돌려서 컴퓨터 대결을 하면 돼요.
